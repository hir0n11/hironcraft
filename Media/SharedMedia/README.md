# SharedMedia alert sounds

Unmodified sound files from the user's installed **WeakAuras_SharedMedia**
package (WeakAuras Team), https://github.com/WeakAuras/WeakAuras_SharedMedia.
Only sounds are bundled here, not the addon's textures, fonts, or library code.

The original `Provided by.txt` attribution and the four Creative Commons
licence texts are retained alongside this file. Individual sound licences
continue to apply, including noncommercial restrictions where specified.
See also the upstream WeakAuras commit history for additional sound credits.

The HironCraft catalogue preserves the original sound labels and file bytes.
`Lich King Apocalypse` references Blizzard's game sound ID 554003 and has no
bundled file. The upstream `Cartoon Hop` entry has no accompanying file in the
installed package and is not offered as a broken choice.
